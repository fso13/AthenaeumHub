## Что зафиксировано

Интерактивный статический макет (HTML/CSS/JS без сборки) в двух темах и на трёх ширинах:

- рейл пространств с **числом непрочитанных** и правилом `99+`;
- сайдбар: навигация, каналы, личные сообщения, unread, presence, футер;
- переписка: плоская лента, даты, реакции, ответы, файлы, видео, голосовые, песни, опросы, стикеры;
- **треды**: ссылка «N ответов», панель треда, создание треда у любого сообщения, ответы;
- **голосовые**: запись с микрофона, таймер, отмена/отправка, карточка с волной и расшифровкой;
- **аудио/видео**: карточки с длительностью, play и скачиванием;
- **песни**: карточка с обложкой, исполнителем, альбомом, годом, жанром; ID3-парсер при загрузке,
  fallback для файлов без тегов;
- **страницы**: Обзор, Файлы, Плагины, Защита, Настройки;
- **окна**: Профиль, Настройки чата (основное/участники/права/опасная зона);
- light/dark, адаптив 390/768/1440, мобильный drawer и sheet;
- логотип-иконка «Сова» вместо огурца (огурец остался стикером).

## Как открыть

```bash
cd design/dashboard
python3 -m http.server 8080
# → http://localhost:8080
```

Или двойным кликом `index.html` (работает `file://`).

Параметры: `?theme=dark`, `?chat=media`, `?chat=atlas&thread=5`, `?space=family&chat=family`,
`?view=overview|files|plugins|security|settings`, `?modal=profile`, `?modal=chat`, `?thread=5`,
`?recording=1`, `?details=0`, `?clean=1`.

## Проверено перед фиксацией

- нет ошибок в консоли на всех состояниях (главная, медиа, тред, страницы, модалки, мобильные);
- нет битых изображений, дублей `id`, горизонтального скролла на 390 px;
- `file://` и HTTP-сервер работают;
- переходы: пространства, чаты, страницы, назад в чат, треды, модалки, темы;
- счётчик 99+ на границе 99/100, пересчёт после `markRead`;
- создание треда у сообщения без ответов, отправка ответа, обновление счётчика/превью;
- загрузка MP3 с ID3 (`TIT2/TPE1/TALB/TYER/APIC`): обложка, артист, альбом, год; fallback без тегов;
- запись голосового: старт/отмена/отправка;
- без backend: только моки и `localStorage` для темы.

## Известные ограничения

- Только моки; API, E2EE, реальные upload/scan/плейлисты не подключены.
- ID3-парсер: MP3/ID3v2.3–2.4; M4A/MP4 и файлы без тегов — fallback (имя, дефолтная обложка).
- Плееры, звонки, каталог плагинов, DLP-аудит и часть настроек — демо-заглушки.
- Счётчик пространства в демо — сумма unread по чатам, поэтому «Общий чат» намеренно показывает 96,
  чтобы был виден `99+`.
- Шрифты системные: SF Pro / Segoe UI; для пиксель-в-пиксель — Inter.

2. Любая правка — новая версия (`v1.1`) с новым `VERSION.md`, `CHANGELOG.md`, манифестом и архивом;
